# EVALUA AI ✦ Analizador Universal & Comparativa Estética

> Plataforma inteligente de evaluación visual, diagnósticos proporcionales, evolución de estilo y asesoría estética personalizada impulsada por inteligencia artificial.

🌐 **Sitio Web Oficial**: [https://evalua-ai.pages.dev](https://evalua-ai.pages.dev)

---

## 🌟 Características Principales

### 1. Ficha Editorial Individual
- **5 Categorías de Evaluación**:
  - ✦ **Facial**: Simetría facial, tercios, balance de mandíbula y pómulos.
  - ✦ **Físico**: Proporciones corporales, postura, porte y biotipo.
  - ✦ **Mirada**: Magnetismo, simetría ocular y expresión.
  - ✦ **Aura & Energía**: Proyección de presencia, confianza y armonía visual.
  - ✦ **Peinado & Estilo**: Volumen, corte, textura y complementariedad con la estructura ósea.
- **Métricas Numéricas**: Escala detallada de 1.0 a 10.0 con desglose por factores clave.
- **Diagnóstico Estilístico**: Puntos fuertes destacados, áreas de mejora y recomendaciones prácticas.

### 2. Comparativa "Antes vs. Después" (Evolución de Estilo)
- **Evaluación Lado a Lado**: Carga dos fotografías (estado base y evolución actual).
- **Delta de Progreso**: Medición precisa de variación (+, -, 0.0) sin inventar diferencias donde no existen.
- **Matriz de Cambios por Área**: Comparación directa de rasgos antes vs. después.
- **Plan de Acción Continuo**: Sugerencias personalizadas para seguir optimizando tu imagen.

### 3. Chat Asesor Interactivo
- Consulta en vivo cualquier recomendación de cortes de cabello, colorimetría, vestimenta o rutina de cuidado.
- Respuestas contextualizadas en base a tu fotografía cargada.

### 4. Exportación y Distribución
- 📄 **Descarga de PDF Editorial**: Informes completos formateados en alta calidad con tipografía sobria y diagramación profesional.
- 📱 **Exportación para Stories (9:16)**: Tarjetas visuales adaptadas para compartir directamente en Instagram, TikTok o WhatsApp.

### 5. Personalización y Tonos de IA
- **Sincero y Honesto**: Evaluación objetiva, técnica y directa sin halagos vacíos.
- **Honesto con Humor**: Diagnóstico veraz aderezado con comentarios ingeniosos y chispa.
- **Modo Claro / Modo Oscuro**: Interfaz minimalista de alto contraste optimizada para cualquier dispositivo.

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/evalua-ai.git
   cd evalua-ai
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Configurar variables de entorno:**
   Crea un archivo `.env` basado en `.env.example`:
   ```env
   GEMINI_API_KEY=tu_api_key_aqui
   ```

4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

5. **Construir para producción:**
   ```bash
   npm run build
   ```
